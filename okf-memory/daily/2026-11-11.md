# Coding Patterns

* The Android assistance toolbar gives the microphone and Settings actions 64 dp touch targets and 16 dp of separation. Compact layouts keep icon buttons with localized accessibility labels.

* Android writes assistance preferences and the guide dismissal flag through the SharedPreferences backend. The previous DataStore is a bounded read-only fallback for valid settings and an existing dismissal flag.

* The assistance home uses a scrollable menu with three full-width mode actions. The active mode puts status, preview and results in the content area and keeps Stop reading in a persistent bottom action. The settings screen uses a persistent Save action.
* Zipformer transcribes a bounded microphone session. Dart maps the transcript to a command result before passing it to the interface.
* Quay lại returns to idle, invalidates the previous assistance request, and closes the camera through the existing session lifecycle.

# Decision Changes

* Zipformer Vietnamese 30M int8 is the sole bundled offline command model. The user reported fairly stable command execution on Realme 5i. Upstream model is CC-BY-NC-ND-4.0 and needs licensing review before product distribution.

# Major Changes

* Android displays SeeMate AI with an adaptive launcher icon and the existing application ID. The first-use guide stores its dismissal locally, plays through offline Vietnamese TTS when available, and can be reopened from Settings.

* Android uses the localZipformer source set with Sherpa-ONNX 2.0.1 for model-enabled builds. Zipformer captures bounded PCM in memory and decodes whole utterances. The model is cached until disposal.
* The temporary microphone transcript screen and Android system recognition comparison were removed once offline Zipformer commands had been evaluated.
