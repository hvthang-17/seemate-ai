# Coding Patterns

* Android detection maps only known model labels and normalizes boxes to the upright camera frame. Results are discarded when their camera session or assistance request is no longer current.
* The production detection adapter returns only current, stable detections. The pilot uses one-to-one same-class association at IoU ≥ 0.50. Recognition requires two same-zone observations in up to three processed frames. Search requires three consecutive same-zone observations. The contract distinguishes stabilizing, no qualifying match, stable matches, and typed failures.
* The assistance camera preview fits within the available content width up to 480 dp and the lesser of 300 dp or 42% of the window height. CameraPreview preserves the image aspect ratio inside the scrollable panel.
* OCR requests one YUV420 frame from the existing camera owner, stops the temporary stream and keeps the preview open. Bundled Latin ML Kit reads the frame in memory. Session invalidation drops late OCR results before playback.
* Android TTS uses an installed offline vi-VN voice, with utterance IDs across the channel. Stop clears active and queued speech and pauses automatic detection announcements until the user selects a mode or target again.
* N3-03 opens a foreground, user-initiated microphone session. The command dispatcher shares the touch actions and v1 target catalog. The Capture command works only in Read text mode.
* Assistance preferences persist in SharedPreferences and update the speech coordinator after load or save. Audio and command transcripts stay in memory.

# Decision Changes

* Detection v1 targets the 16 classes supported by the bundled EfficientDet-Lite0 evaluation model. Wallet, Keys, and Bread move to a future model upgrade. Recognition and the target picker share the v1 label catalog.
* The packaged MediaPipe Tasks runtime and exact int8 model are confined to a local evaluation build selected by `seemateModelDir`. That build removes the app's INTERNET permission. The regular build uses a typed missing-model implementation pending privacy and artifact distribution decisions.

# Major Changes

* Windows real-photo probes using the exact int8 model recorded one qualifying bottle detection and two misses in the N2 feasibility report.
